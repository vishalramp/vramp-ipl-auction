# VRAMP IPL Auction Arena

A new server-backed multiplayer auction build.

## Included
- Up to 10 franchise players
- Public/private-ready room architecture
- Spectator join flag
- Real-time synchronized bids
- Host controls
- Timer and reset settings
- IPL bid increments
- Purse, squad and overseas limits
- Activity feed
- Mega / Mock auction mode selector
- Mobile responsive UI
- No sign-up
- Small VRAMP watermark

## Run
1. Install Node.js 18+
2. In this folder run: npm init -y
3. Run: npm install ws
4. Run: node server.js
5. Open http://localhost:3000

For internet play, deploy this folder to a Node-capable host (for example Render/Railway/Fly.io) rather than a static file host.
